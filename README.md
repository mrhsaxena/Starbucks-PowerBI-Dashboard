☕ Starbucks Beverage Analytics Dashboard | Power BI

📌 Project Overview

This project presents an interactive Starbucks Beverage Analytics Dashboard built using Microsoft Power BI. It provides a visual overview of beverage categories and nutritional metrics to make data easier to explore and understand.

🎯 Project Objectives

- Analyze beverage categories and their distribution.
- Explore average sugar and calorie values.
- Compare caffeine levels across beverage categories.
- Highlight beverages with high caffeine content.
- Present key metrics in a clear, interactive dashboard.
